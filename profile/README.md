# Welcome to SCENE 🌍🧠

### Simons Collaboration on Ecological Neuroscience

*Studying how brains interact with the world*

SCENE is a hypothesis-driven, theory-first, multi-species consortium uncovering general principles of brain function through an **ecological perspective**: studying perception, cognition, and action in the context of the affordances available to different agents.

This organization is where SCENE shares its **code, pipelines, and best practices**. We're glad you're here! 👋 It is overseen by the [SCENE Data Science Core Team](https://www.project-scene.org/research/data-science-core)
